## 1. Цель работы

Разработать сбалансированное дерево (B-Tree) на языке C для хранения пар key-value. Реализовать операции вставки, удаления и поиска элементов с сохранением структуры B-дерева. Реализовать CLI с поддержкой ввода из файла.



## 2. Реализация
* Реализовано расщепления (split) переполненных узлов при вставке и слияние/заимствование (merge/borrow) ключей у соседних узлов при удалении (в функции `fill` `src/BTree.c`). Дерево всегда остается сбалансированным.
* Реализовано удаление с ребалансировкой, добавление новых узлов, поиск значения по ключу, вывод дерева
* В качестве ключей используются строки длинны не более 6, упорядоченные лексикографически. Значения имеют тип данных `double`.

## 3. CLI и работа с файлами

В `main.c` реализован разбор аргументов командной строки. Поддерживаются флаги:
```
--input <file>	Обязательный флаг для чтения из файла (если не указан --test). 
--output <file>	Файл для записи результатов. Если не указать будет выводить в поток
--test	        Запуск unit-тестов (Google Test). Программа завершается после выполнения тестов.
--help	        Вывод справки по доступным опциям.
```
Если не указать никакого `--input` то программа запускается в интерактивном режиме

## 4. Обработка файла

Программа обрабатывает входящие инструкции на основе этой схемы:

* `1 <key> <value>` - Вставка пары в дерево. При успехе выводит `OK`.
* `2 <key>` - Удаление ключа и связанного значения. При успехе выводит `OK`.
* `3` - Обход дерева с выводом всех элементов
* `4 <key>` - Поиск значения по ключу. Возвращает `value: <число>` или `key not found`.
